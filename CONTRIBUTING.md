# Contributing

Bug reports should include the Linux distribution and version, Qt version, CPU, GPU, graphics-driver version, OpenCL runtime, and the exported On Point System Optimizer diagnostic information when performance or GPU behavior is involved.

Keep changes focused on precision photo correction, restoration, printing, import/export reliability, performance and approachable Linux usability. On Point is not intended to become a compositing or layer-based graphics editor.

By submitting a contribution, you agree that it may be distributed under GPL-3.0-or-later.
